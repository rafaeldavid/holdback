# Security

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository. Please do not open a public issue.

Scope: the settlement contracts (`contracts/src`), the operator API (`apps/operator`), the judgment pipeline (`packages/judgment`) and the public demo at escrow.stream.

Everything here runs on a local chain, a testnet or the in-process SimChain with test tokens. No real funds are at risk, and there is no bounty.
