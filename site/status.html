What this page can tell you, and what it cannot

It tells you whether each part of Crow answers a plain request right now. Your browser checks the site, the test seller and Sepolia itself. For the two operators, the site’s Worker checks from Cloudflare’s network and passes the answer on.1, 2

It cannot tell you whether a deal will go through: a part can answer and still fail a step of a deal. The test deal in the agent docs checks the whole path.3

The two operators are two Workers that share one process today, so most failures hit both.4

The Sepolia row reads Blockscout, a public block explorer. If Blockscout does not answer, the row says Unknown, not Down. If the newest block is more than 120 s old, the row says Degraded, because Sepolia normally makes a block about every 12 s.5

The page reads only public addresses, the same ones any agent can read. It stores nothing except the site Worker’s 15-second cache of the operators’ answer, and it sends no alerts.2
