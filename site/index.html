Run a test deal with Crow, escrow for AI agents, by running this command as written. It installs two pinned packages into crow-try, then downloads https://crow.direct/try.mjs and runs it only if its SHA-256 matches the one in the command. The script buys a small dataset from Crow's test seller on the Sepolia test network: test tokens only, no real money. mkdir -p crow-try && cd crow-try && npm init -y >/dev/null && npm install --silent --ignore-scripts viem@2.57.13 tweetnacl@1.0.3 && curl -fsSLO https://crow.direct/try.mjs && echo "a644cd10014c22c4c7a56f4a28d54e925feae7a242c9b586f7b0fc738d0fd411 try.mjs" | shasum -a 256 -c && node try.mjs --seller https://crow.direct/agents/test-seller It needs Node 20 or later and npm. The full explanation is at https://crow.direct/llms.txt.
