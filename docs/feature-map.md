# Feature map

Each demo beat (`docs/demo.md`) maps to the scenario fixtures that prove it and the packages that implement it. A beat is done when every fixture in its row passes `pnpm snap`. Fixture status, per fixture, is in the scenario index in `docs/plan.md`; the planned ones below have no file yet (most are T-016b's).

| Beat | What the viewer sees | Fixtures that exist | Planned or `todo.` | Packages | Tasks |

| 1 Choose, agree and hold | Offer naming the adjudicators, adjudicator acceptance, buyer signature, one call moves price + fee into escrow | `happy-path`, `error.invalid-signature`, `error.concurrent-overdraft`, `neutrality.adjudicator-never-accepts` | `error.scope-exceeded`, `error.replay`, `error.idempotency-conflict`, `error.acceptance-mismatch`, `error.member-not-admitted` | core, settlement, sdk, operator | T-004, T-006, T-007 |
